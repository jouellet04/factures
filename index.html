Sauvegarde des données

Les données sont gardées dans ce navigateur, sur cet ordinateur. Gardez vos sauvegardes dans un endroit sûr (clé USB, iCloud, Google Drive…) pour ne rien perdre, ou pour transférer vos données sur un autre ordinateur.

Aide

Comment faire une facture

  1. Notez vos cours, séances et services dans Activités, au fil du temps. Chacun peut se compter en quantité, en heures ou en minutes.
  2. Quand c'est le moment de facturer, cliquez sur Créer la facture pour regrouper tout ce qui reste à facturer à ce client, ou cochez seulement certaines activités.
  3. Cliquez sur Enregistrer et télécharger le PDF, puis envoyez le fichier à votre client.
  4. Quand le client a payé, cliquez sur ✓ Payée dans la liste des factures.

Suivre ses finances

Notez vos achats d'entreprise dans Dépenses. L'onglet Finances calcule vos revenus, vos dépenses et votre bénéfice estimé, par mois et par catégorie. Vous pouvez aussi les exporter pour votre comptable.

Où sont mes données ?

Vos clients, vos factures et vos dépenses restent uniquement sur cet appareil, dans ce navigateur. Rien n'est envoyé sur Internet.

Conséquence importante : si l'appareil brise ou si les données du navigateur sont effacées, tout est perdu sans sauvegarde.

Les sauvegardes

Un fichier de sauvegarde est téléchargé automatiquement environ une fois par mois, quand vous enregistrez une facture. Vous pouvez aussi en faire un à tout moment dans Paramètres.

Gardez ces fichiers dans un endroit sûr (iCloud, Google Drive, clé USB). Pour tout récupérer, y compris sur un nouvel appareil : Paramètres → Restaurer une sauvegarde.

Le navigateur peut demander d'autoriser les téléchargements la première fois. Acceptez, sinon les PDF et les sauvegardes ne seront pas enregistrés.

Installer l'outil comme une application

Installez-le une seule fois, puis ouvrez-le toujours de la même façon : chaque navigateur et chaque application installée garde ses propres données.

  • Mac (Safari) : menu Fichier → Ajouter au Dock (macOS Sonoma ou plus récent).
  • Windows, Mac ou Linux (Chrome, Edge) : cherchez l'option Installer dans le menu du navigateur.
  • iPhone ou iPad (Safari) : bouton Partager → Sur l'écran d'accueil.
  • Android (Chrome) : menu ⋮ → Ajouter à l'écran d'accueil.

Si vous aviez déjà des données dans le navigateur, faites une sauvegarde avant d'installer, puis restaurez-la dans l'application.

Choisir où vont les fichiers

Le dossier est choisi par le navigateur, pas par l'outil. Cherchez Téléchargements dans les réglages de votre navigateur pour le changer.
